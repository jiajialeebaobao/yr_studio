# 怡然集瑜伽工作室

Next.js App Router、TypeScript、Prisma 和本机 SQLite。原版 `index.html` 保留作参考；原始图片、海报和 Python 脚本未删除，网站只公开使用中的五张图片。

## 本地启动

需要 Node.js 24 LTS 和 npm。

```sh
npm ci
npm run setup
npm run dev
```

打开 http://127.0.0.1:3000 ，后台为 `/admin`。`setup` 首次生成 `.env` 内的唯一管理员密码和预约密钥，重复执行不会重置密码或数据库。用编辑器打开 `.env` 查看 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`。请勿提交 `.env`。

数据库初始为空。先登录后台创建实际日期的场次，顾客即可在首页选择并预约。未把旧 HTML 的示例课表作为真实场次。

## 成班任务

开发或正式运行时，在另一个终端启动：

```sh
npm run worker
```

任务每分钟处理一次，重启后补处理；页面/API 请求也会补处理。可用 `npm run worker -- --once` 执行一次，或由系统任务管理器每分钟调用。任务与网页必须使用同一数据库和环境变量。

所有时间显示为北京时间，数据库以 UTC 保存。至少提前 4 小时可预约，至少提前 3 小时可免费取消（包含截止时刻）。免费取消窗口关闭后，小班满 3 人确认开课，否则停课且预约标记为“未成班”。私教限 1 人、预约即确认。逾时取消联系门店；本项目不扣款、不扣课、不发送短信或微信通知。

## 预约链接与后台

提交成功后展示可复制的专属链接。相同提交编号重试返回同一链接；数据库仅保存令牌摘要。链接可查询和取消该预约，请勿公开。无账号或短信找回功能，如遗失链接请联系门店，后台可查姓名与手机号。

后台可创建场次、编辑/删除无预约记录的场次、查看记录以及停课。已有任何预约记录后禁止改期、修改或删除，需停课再新建，防止顾客原链接指向变化的课程。停课原因显示在预约详情中。

管理员会话 8 小时失效，退出立即撤销。登录和预约接口有限流，同源检查和请求体大小限制。修改管理员密码后，如需立即注销所有既有会话，可停止服务并清空 `AdminSession` 表；不在文档中写入真实凭据。

## 检查与生产运行

```sh
npm run typecheck
npm test
npm run build
npm run test:api
npm start
```

使用普通 Node.js 服务器及持久磁盘；不能使用纯静态导出或无持久磁盘的 Serverless 部署。将 `.env` 中的数据库 URL 指向持久磁盘，并保留 `BOOKING_SECRET`（更换会影响旧提交的幂等链接恢复）。HTTPS 反向代理部署时设置 `APP_ORIGIN` 为完整公开域名（例如 `https://yoga.example.com`），保留正确的 Host/协议。应用默认只监听 127.0.0.1。部署后同时运行独立成班任务。

## 数据迁移、备份与恢复

```sh
npm run db:generate
npm run db:migrate
npm run db:backup
```

数据库默认位于 `prisma/studio.db`。备份使用 SQLite `VACUUM INTO` 生成一致快照到 `backups/`，可在服务运行时执行。备份包含顾客联系方式，应存放在受控目录。

恢复时停止网页与任务进程，另行保留当前数据库，再将选定快照复制到配置的数据库路径；恢复完成后运行迁移并重新启动网页和任务。`.env` 应另行安全备份。不要将数据库复制到 `public/`。

单元/集成测试在独立临时数据库运行，结束后清理，不向正式数据库注入测试场次。浏览器验收使用独立 QA 数据库。
